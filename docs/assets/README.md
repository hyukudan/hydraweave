# Hydraweave artwork

Original geometric artwork for this project: four heads rise from a shared base, with alternating crossings to suggest nodes and GPUs weaving one inference. The mark uses flat teal and indigo strokes; the wordmark uses a system sans-serif font stack. No gradients or external images are used.

- `hydraweave-logo.svg` and `hydraweave-logo.png`: light background, square composition.
- `hydraweave-logo-dark.svg` and `hydraweave-logo-dark.png`: dark background, square composition.
- `hydraweave-mark.svg`: compact square mark for favicon sizes, also used by the portal icons.

The PNG logo exports are 512 × 512. The SVGs remain the editable masters. Artwork is distributed under the project license.
