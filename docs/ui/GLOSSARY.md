# Hydraweave UI glossary

Use **model** for a model the user can choose, and **setup** for a saved way to run it. Use **engine** only for the
binary shown in Updates. Use **node** for a host, **this computer** for the computer running the local portal, and
**GPU slot** for an allocated GPU lease. Avoid calling these items engines, presets, profiles, machines, workers,
controllers, or GPU turns in user-facing copy.
